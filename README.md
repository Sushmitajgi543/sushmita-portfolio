# Sushmita Kumari — Portfolio

A Vercel-ready React + Vite portfolio for Sushmita Kumari, designed as a dark, editorial, AI-native engineering portfolio.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Before publishing
1. Replace `sushmita@example.com` in `src/main.jsx` with your real email.
2. Replace the placeholder GitHub and LinkedIn URLs with your profiles.
3. Add project screenshots/links when available.
4. Deploy the project to Vercel.
